# اپِ اندرویدِ لمدا (Python/Kivy)

این اپ همون کارِ وب‌سرورِ خودِ ربات (`/`) رو انجام می‌ده: چت متنی + نمایشِ وضعیت/مود، ولی به‌صورتِ یه اپِ بومیِ اندروید نه صفحه‌ی مرورگر.

## چطور کار می‌کنه
اپ مستقیم به همون HTTP endpointهایی وصل می‌شه که تو کدِ ESP32 (`Lamda_S3_37.txt`) هستن:
- `GET /chat?msg=...` → پیام می‌فرسته، جوابِ لمدا رو می‌گیره.
- `GET /moodStatus` → یه JSON با `state`، `moodScore`، `online`، `needsReconciliation`، `tempC` برمی‌گردونه (این endpoint جدیده، تو `Lamda_S3_37.txt` اضافه شده).
- `GET /state?mode=...` → دکمه‌هایِ سریع (خوشحال/غمگین/عصبانی/...) همینو صدا می‌زنن.
- `GET /setOnline?value=0/1` → دکمه‌هایِ آنلاین/آفلاین.

هر دو (گوشی و ربات) باید تو یه شبکه‌ی وای‌فای باشن. آی‌پیِ ربات رو از رو سریال مانیتور (موقعِ وصل شدنِ وای‌فای چاپ می‌شه) یا از تنظیماتِ روتر پیدا کن و تو فیلدِ پایینِ اپ وارد کن.

## اجرا رو کامپیوتر (تست سریع، قبل از ساختِ APK)
```
pip install kivy requests
python main.py
```

## ساختِ APK (رویِ لینوکس یا WSL — من نمی‌تونم از همین‌جا APK بسازم چون به شبکه و ابزارهایِ اندروید دسترسی ندارم)
```
pip install buildozer cython
buildozer android debug
```
اولین بار طولانی می‌شه چون Android SDK/NDK رو خودش دانلود می‌کنه (به اینترنتِ خوب نیاز داره). فایلِ خروجی تو `bin/lamdaapp-1.0-debug.apk` ساخته می‌شه، همونو رو گوشیت نصب کن.

## نکات
- اگه ربات آفلاینه (`persistentChatMode != 2`)، `/chat` همچنان جواب می‌ده چون خودِ ربات آفلاین هم جواب می‌ده؛ ولی اگه اصلاً روشن/وصل نباشه، اپ پیامِ خطا نشون می‌ده.
- `DEFAULT_HOST` تو بالایِ `main.py` رو می‌تونی به آی‌پیِ ثابتِ ربات (اگه تو روتر IP ثابت گرفته) از قبل تنظیم کنی.
